#### 💥 Introduction

Hey! I'm Mahnoor, a teenager who is a full-stack developer and enjoys building things, experimenting with technologies, and figuring out how stuff works behind the scenes.

I work across frontend, backend, and mobile development, with an interest in software architecture, databases, and machine learning.

- 💻 Currently building full-stack applications with **Angular, TypeScript, C#, and ASP.NET Core**.
- 📱 Experienced in cross-platform mobile development using **Flutter and React Native**.
- 🗄️ Exploring backend architecture, REST APIs, database design, and authentication.
- 🤖 Experimenting with machine learning and Python.
- 🌱 Always learning, building, and occasionally starting projects just because an idea wouldn't leave my head.

#### 🚀 Main Projects

- ✍️ [Type-It-Out Frontend](https://github.com/mahnoor-awais/Type-It-Out-Frontend) — Angular frontend for a social article-writing platform.
